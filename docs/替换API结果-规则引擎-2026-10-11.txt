 这是什么
--------------------------------------------------------------------------------
 进高级模式之后，你可以**用中文写规则**来编辑 API 的返回值。
 语法刻意做得像易语言（`当 … 时 …`）；匹配模式既可以是字面量，
 也可以是**正则**（用 /.../ 包起来）。

    当 <面> [的 <字段>] <算子> <模式> 时 <动作>

    面   : 注册表值 | 注册表枚举 | 剪贴板
    字段 : 值名 | 键路径 | 子键名 | 格式      （可省，用该面的默认字段）
    算子 : 等于 | 含 | 匹配 | 开头 | 结尾     （匹配 = 正则）
    模式 : "文本"  或  /正则/
    动作 : 替换为 "文本" | 替换为 全零 | 替换为 全FF | 替换为 空
           | 隐藏（只对枚举面） | 拒绝 | 放行

 ★ 求值：**按加入顺序，第一条命中的生效**（first-match wins）。
   一条都没命中 ⇒ 回落控制台的内置默认行为（fill / hide / fakeclip）——
   所以「加规则」是**叠加**，不会把之前调好的默认行为弄丢。
 ★ 加规则两种写法等价：**直接敲以「当」开头的一行**，或 `rule add <规则>`。
   其余命令：`rule list | del <序号> | clear | load <文件> | save <文件> | test <面> <值> | help`。
 ★ 语法写错**当场报错、不进规则表**（自测里 4 条错规则全被挡下，见
   `build_spoof_console.sh --selftest` 第 3/3 段）。

 本次演示真实敲进去的规则：
   当 注册表值 的 值名 匹配 /Pass.*/ 时 替换为 "***-改过了-***"
   当 剪贴板 的 格式 等于 文本 时 替换为 "这段是假的"
   当 注册表枚举 的 子键名 匹配 /Secret|Hidden/ 时 隐藏
   当 注册表值 的 值名 等于 "Password" 时 放行

 替换判据与生产**同源** —— 直接 #include 三个 codec 头（铁律 195）；
 规则只决定"该不该换、换成什么"，**怎么换**仍走生产代码。

 顺带把三道题的答案讲清楚：

 [第 1 题] 正确答案 C
    `Nt*` 层**不吃**伪句柄。advapi32 的 RegOpenKeyExW(HKEY_CURRENT_USER, ...) 能跑，
    是因为它**自己**先把伪句柄换成了真句柄 —— 这个替换把坑盖住了。
    Nt* 只有两条路：① RootDirectory=真键句柄 + 相对名；② RootDirectory=NULL +
    绝对 NT 路径（\REGISTRY\USER\<SID>\...）。

 [第 2 题] 正确答案 B
    vtable 是**模块级共享**的：patch 一次，所有实例一起变。所以必须
    「补丁全局、策略逐对象」—— 要不要替换按**实例**记；
    而原件必须按 **vtable** 存，否则第二个实例再来 patch 时，
    会把**已经被改过**的地址当成「原件」存下来，链就断了。

 [第 3 题] 正确答案 A
    WOW64 默认把 32 位进程的 HKLM\SOFTWARE 重定向到 HKLM\SOFTWARE\WOW6432Node。
    KEY_WOW64_64KEY 强制走 64 位视图，KEY_WOW64_32KEY 强制走 32 位视图。
    （注意 HKCU 也重定向，但只对 HKCU\Software\Classes 那一段。）
