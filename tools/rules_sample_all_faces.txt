# 规则表示例 —— 五个面各来一条（v135）
#
# 用法：
#   bash tools/spoof_verify_all.sh --rules tools/rules_sample_all_faces.txt
#   （会用生产同源 codec 把每一条**真跑一遍**，打印"改前 -> 改后"的真实字节）
#
# ★ 这只是**示例**，不要直接当成生产配置用：
#   下面那些模式串（secret / token / DemoCapture …）是为了让夹具能命中，
#   不是建议你替换这些对象。
# ★ 真正生效还要求对应的 ini 总开关是开的（规则与开关是**叠加**关系）：
#   文件面 → spoof_file=1 + protect_file=<前缀>
#   截屏面 → spoof_screen=1（要换图再加 spoof_screen_image=<BMP 路径>）
# ★ 匹配是"第一条命中即生效"⇒ 越具体的规则要放越前面。

# ---- 注册表值：正则匹配值名 -> 换成固定文本 ----
当 注册表值 的 值名 匹配 /Pass.*/ 时 替换为 "***"

# ---- 剪贴板：按格式名匹配 -> 换掉内容 ----
当 剪贴板 的 格式 等于 文本 时 替换为 "[已替换]"

# ---- 注册表枚举：子键名含 Secret -> 从列表里去掉 ----
当 注册表枚举 的 子键名 含 "Secret" 时 隐藏

# ---- 文件：按被读文件的完整路径匹配 ----
当 文件 的 路径 含 "secret" 时 替换为 全零
当 文件 的 路径 含 "token" 时 替换为 全FF
当 文件 的 路径 含 "config" 时 替换为 "[已替换的文件内容]"
当 文件 的 路径 含 "public" 时 放行

# ---- 截屏：按**调用方进程的 exe 名**匹配（不是窗口标题）----
当 截屏 的 进程 含 "obs" 时 替换为图 "C:\fake\desktop.bmp"
当 截屏 的 进程 含 "WeChat" 时 放行
当 截屏 的 进程 含 "notepad" 时 替换为 全零
